## 🧠 Mimir — Autonomous AI Research Agent

> **An autonomous research system designed to investigate topics, gather information, verify findings, and generate structured research outputs.**

Mimir explores how multiple AI agents can work together to perform research instead of simply generating a single LLM response.

### Architecture

```text
                    USER QUERY
                         │
                         ▼
                  ┌─────────────┐
                  │   PLANNER   │
                  └──────┬──────┘
                         │
                         ▼
                  ┌─────────────┐
                  │  RESEARCHER │
                  └──────┬──────┘
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
        Web Search              Knowledge Base
              │                     │
              └──────────┬──────────┘
                         ▼
                  ┌─────────────┐
                  │  VERIFIER   │
                  └──────┬──────┘
                         │
                         ▼
                  ┌─────────────┐
                  │   WRITER    │
                  └──────┬──────┘
                         │
                         ▼
                  RESEARCH REPORT
```

### Built With

`Python` `LangGraph` `LangChain` `Groq` `LLMs` `Web Search` `ChromaDB` `RAG`

## 📚 PDF RAG Research Assistant

A document question-answering system that allows users to interact with uploaded PDF documents using Retrieval-Augmented Generation.

### Pipeline

```text
PDF
 ↓
Document Loader
 ↓
Text Splitting
 ↓
Embeddings
 ↓
Vector Database
 ↓
Semantic Retrieval
 ↓
LLM
 ↓
Answer
```

### Technologies

`Python` `LangChain` `Mistral` `ChromaDB` `PyPDF` `RAG`
